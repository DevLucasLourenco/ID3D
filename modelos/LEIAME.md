# modelos/

Coloque aqui os PDFs 3D (ou arquivos `.prc`) que devem aparecer na tela inicial do ID3D
quando ele é aberto pelo servidor (`npm start`). É a forma prática de abrir um modelo em um
tablet, sem precisar copiar o arquivo para o aparelho.

O conteúdo desta pasta **não vai para o git** (veja `.gitignore`): modelos reais não devem
ser publicados neste repositório.
